# 🏛️ StoneAge Video Bot

Автоматический бот для генерации и публикации коротких видео в X (Twitter) с данными нефтяного рынка и ценами на газ.

## 🚀 Как это работает
1. **Генерация:** Скрипт `stoneage_generator.py` микширует шум дороги, живой эфир радиостанций (Bloomberg, WNYC, NPR) и видео с дорожных камер Вирджинии.
2. **Маркет:** На видео накладываются актуальные цены на нефть Brent и бензин (Gas) в Вирджинии.
3. **Публикация:** Скрипт `stoneage_tweeter.py` использует официальный X API (с поддержкой Chunked Upload) для выгрузки видео. Перед постом нового видео бот удаляет предыдущий твит, чтобы в профиле всегда был только один актуальный ролик.
4. **Расписание:** Бот запускается дважды в день (9:01 и 14:31) через системный планировщик.

## 🛠️ Установка и настройка
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте файл `.env` на основе примера:
   ```env
   X_API_KEY=your_key
   X_API_SECRET=your_secret
   X_ACCESS_TOKEN=your_token
   X_ACCESS_TOKEN_SECRET=your_token_secret
   ```
4. Добавьте свои шрифты и файлы слоев (`.ttf`, `.png`).
5. Настройте расписание: `./set_stoneage_schedule.sh`.

## 📜 Основные команды
- `./run_stoneage.sh` — запустить полный цикл вручную (генерация + пост).
- `./set_stoneage_schedule.sh` — обновить расписание в планировщике.
- `python3 stoneage_tweeter.py --skip-generator` — отправить в X последнее сгенерированное видео без повторной генерации.

## 📝 Текст твита
Бот формирует текст в формате:
```text
Brent $103.3 ▼ | Gas, VA $4.03 ▼
online @VaDOTNOVA camera Fairfax
news from @BloombergRadio
```
